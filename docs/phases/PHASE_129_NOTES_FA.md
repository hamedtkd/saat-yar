# فاز ۱۲۹ — ساخت موجودیت وابسته بدون خروج از جریان

## هدف

کاهش اصطکاک فرم‌های رابطه‌ای. کاربر نباید برای ساخت پروژه، ابتدا فرم را رها کند، به صفحه مشتری‌ها برود، مشتری بسازد و دوباره به پروژه برگردد.

## تغییرات

- رفع تست قدیمی فاز ۵۲ و هماهنگی آن با Navigation دو سطحی Settings فاز ۱۲۸.
- افزودن `Dialog` رسمی Radix/shadcn به‌عنوان Primitive عمومی فرم‌های Modal.
- افزودن دکمه همیشگی «مشتری جدید» کنار انتخاب مشتری در فرم پروژه.
- نمایش Empty State واضح وقتی مشتری فعال وجود ندارد.
- ساخت مشتری داخل Modal و انتخاب خودکار همان مشتری در پروژه جاری.
- افزودن «پروژه» به عملیات هر مشتری و ساخت پروژه مرتبط بدون ترک صفحه مشتری‌ها.
- استخراج مسیرهای `createClient` و `createProject` در Business Actions تا Persistence در Modalها تکرار نشود.

## قرارداد UX

- Trigger ساخت موجودیت وابسته حتی وقتی لیست خالی نیست در دسترس می‌ماند.
- موجودیت تازه‌ساخته‌شده بلافاصله به رابطه جاری متصل می‌شود.
- Modal فرم عادی است، بنابراین از Dialog رسمی استفاده می‌کند؛ AlertDialog برای عملیات تأییدی/مخرب باقی می‌ماند.
- داده و Schema تغییر نکرده‌اند؛ AppData همچنان v17 است.

## ادامه

فاز ۱۳۰ همین الگو را به رابطه‌های دیگر مثل Invoice → Client/Project و Timer/Expense → Project تعمیم می‌دهد.
