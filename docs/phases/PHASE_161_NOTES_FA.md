# فاز ۱۶۱ — پالیش چیدمان برنامه کاری

این فاز بعد از Phase 160 و روی همان قرارداد ناهار/ساعت خروج انجام می‌شود. هدف فقط تمیزکردن alignment، hierarchy و رفتار Responsive بخش بالای «برنامه کاری هفتگی» است؛ بدون تغییر منطق محاسبه، Schema یا داده‌های ذخیره‌شده.

## مسئله

بعد از اضافه‌شدن کنترل‌های «هدف کار خالص هفتگی» و «ناهار پیش‌فرض برای همه روزها» در Phase 160، سه ناحیه بالای برنامه کاری از نظر ارتفاع، فاصله داخلی، تراز کنترل‌ها و helper text هم‌سطح نبودند. نتیجه در دسکتاپ شلوغ و نامتوازن دیده می‌شد، مخصوصاً کارت ناهار و کنترل «جزو کارکرد».

## تغییرات UI

- سه ناحیه بالای برنامه کاری به سه کارت هم‌ارتفاع با border، surface و padding مشترک تبدیل شدند.
- Grid در دسکتاپ سه ستون متعادل دارد؛ در تبلت دو ستون است و کارت توضیح عرض کامل می‌گیرد؛ در موبایل کارت‌ها به‌صورت stack نمایش داده می‌شوند.
- کارت «ناهار پیش‌فرض» دو کنترل مشخص «مدت ناهار» و «نحوه محاسبه» دارد و Checkbox دیگر کنار متن و Field فشرده نمی‌شود.
- کارت «هدف کار خالص هفتگی» ورودی عدد و واحد «ساعت» را روی یک ردیف تراز می‌کند و توضیح میانگین روزانه در پایین کارت ثابت می‌ماند.
- کارت توضیح «برنامه کاری هفتگی» خلاصه‌تر شد و دو نکته اصلی قرارداد کار خالص و ناهار بدون حقوق را به‌شکل قابل اسکن نمایش می‌دهد.
- min-widthهای قبلی که باعث ناهماهنگی کارت‌ها می‌شدند حذف شدند.

## قراردادهای حفظ‌شده از Phase 160

- هدف هفتگی همچنان «کار خالص» است.
- ناهار بدون حقوق زمان خروج پیشنهادی را به اندازه مدت واقعی ناهار عقب می‌برد.
- ناهار با حقوق جزو کارکرد محسوب می‌شود.
- تغییر جمعی یا روزانه ناهار، هدف کار خالص را ناخواسته تغییر نمی‌دهد.
- تنظیم جمعی ناهار و override روزانه هر دو باقی می‌مانند.

## داده و Release

- Schema روی `v17` باقی می‌ماند.
- نسخه Package همچنان `2.3.1` است؛ این فاز post-release و قبل از Finalization نسخه بعدی انجام می‌شود.
- Migration و Dependency جدیدی اضافه نشده است.
