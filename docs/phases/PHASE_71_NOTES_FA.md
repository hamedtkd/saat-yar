# فاز ۷۱ — جزئیات مالک تایمر و تأیید انتقال کنترل

## هدف

شفاف‌کردن مالکیت تایمر زنده در چند تب، بدون نمایش شناسه‌های فنی یا اطلاعات حساس مرورگر.

## تغییرات

- افزودن نام خلاصه مرورگر و سیستم‌عامل به قفل مالکیت تایمر.
- نمایش زمان نسبی آخرین Heartbeat مالک فعلی.
- نمایش اطلاعات مالک در بنر هشدار.
- افزودن Alert Dialog تأیید قبل از انتقال کنترل.
- حفظ سازگاری با قفل‌های قدیمی فاقد `deviceName`.

## حریم خصوصی

اطلاعات ذخیره‌شده فقط یک برچسب عمومی مانند `Chrome روی Windows` است. User-Agent کامل، IP، نام سیستم و شناسه سخت‌افزاری ذخیره نمی‌شوند.

## کیفیت

تست فاز ۷۱ تبدیل نام دستگاه، فرمت Heartbeat، انتشار اطلاعات مالک و Dialog انتقال کنترل را پوشش می‌دهد.
