# فاز ۱۶۳ — بازیابی نشست و کنتراست Accent

## هدف

این فاز دو ناهماهنگی پس از انتشار 2.3.1 را می‌بندد:

1. کنترل‌های پرشده در تم‌های فیروزه‌ای و آبی متن/آیکن تیره داشتند.
2. Reload یا بستن ناگهانی می‌توانست رکورد روز باز را خودکار ببندد، بدون مسیر صریح برای ادامه کار.

## تغییرات

- `--accent` همچنان رنگ هویتی تم است و برای Focus، نمودار و سطوح نرم استفاده می‌شود.
- `--accent-fill` برای Filled Controlها اضافه شد. فیروزه‌ای و آبی برای این سطح به نسخه تیره‌تر و دارای کنتراست کافی با سفید نگاشت می‌شوند.
- Button، Checkbox، Sidebar active state، Date Picker و Filled stateهای مشابه از `--accent-fill` استفاده می‌کنند.
- `beforeunload` دیگر Pending Close جدید تولید نمی‌کند؛ Reload عادی با Heartbeat تازه، رکورد را باز نگه می‌دارد.
- Auto-close قدیمی و Stale Heartbeat همچنان برای بازیابی ایمن داده پشتیبانی می‌شوند.
- رکورد Auto-close روز جاری می‌تواند Resume شود. هنگام Resume، فاصله بین آخرین فعالیت و زمان بازگشت به‌عنوان وقفه بدون حقوق ذخیره می‌شود و `end` دوباره باز می‌شود.
- رکورد تاریخی فقط مسیر «ویرایش این روز» را دارد و Resume برای روزهای گذشته ارائه نمی‌شود.
- Schema روی v17 باقی مانده و Dependency/Migration جدیدی اضافه نشده است.

## قرارداد تست

- Filled Accent تم‌های فیروزه‌ای/آبی foreground سفید دارند.
- Runtime و Bootstrap هر دو `--accent-fill` را تنظیم می‌کنند.
- Resume رکورد Auto-close را باز می‌کند و Gap را به Break بدون حقوق تبدیل می‌کند.
- Gap بازیابی وارد کارکرد خالص نمی‌شود.
- Reload عادی دیگر `createPendingClose` را در Persistence صدا نمی‌زند.
- مسیر Today اکشن Resume را تا Controller سیم‌کشی می‌کند.

## Revision 2 — همگام‌سازی قرارداد تاریخی Phase 101

پس از اجرای Full Gate روی محیط اصلی، تنها شکست مربوط به تست تاریخی Phase 101 بود که هنوز Active Sidebar را مستقیماً با `--accent` بررسی می‌کرد. از Phase 163 به بعد Filled Controlها عمداً از `--accent-fill` استفاده می‌کنند و foreground آن‌ها از `--accent-foreground` می‌آید؛ بنابراین تست تاریخی با قرارداد جدید همگام شد. این Revision هیچ تغییری در رفتار Runtime، Session Recovery یا Schema ایجاد نمی‌کند.
