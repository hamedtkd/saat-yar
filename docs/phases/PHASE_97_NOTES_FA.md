# فاز ۹۷ — تکمیل استانداردسازی مخزن و راهنمای انگلیسی Agentها

## مبنا

این فاز روی آخرین وضعیت `main` پس از Commit `53e445b` طراحی شده است. فاز ۹۶ واقعی مخزن، پاک‌سازی پایدار پروفایل Smoke Test در Windows بود؛ بنابراین شماره فاز بدون فرض اجرای دقیق برنامه قدیمی ادامه یافته است.

## هدف

بستن بخش باقی‌مانده استانداردسازی مخزن، هم‌راستا کردن راهنمای مشارکت با Quality Pipeline فعلی و فراهم‌کردن مسیر روشن برای Agentهای انگلیسی‌زبان، بدون تغییر رفتار محصول.

## تغییرات

- افزودن `docs/agents/AGENT_GUIDE_EN.md` به‌عنوان راهنمای انگلیسی معماری، داده، UI، تست و تحویل.
- افزودن `docs/agents/CHANGE_CHECKLISTS.md` برای تغییرات Schema، Migration، Backup، IndexedDB، Draft، Accessibility و Release.
- به‌روزرسانی `AGENTS.md` با لینک دو راهنما، قرارداد داده و اجرای `check:release`.
- اصلاح `CONTRIBUTING.md`: نام صحیح مخزن، دستورهای فعلی `check:quality` و `check:release` و الزامات داده.
- تقویت قالب Pull Request با چک‌لیست شواهد، ایمنی داده، UI و مستندات.
- به‌روزرسانی فهرست مستندات و بستن آیتم‌های واقعاً تکمیل‌شده استانداردسازی در بک‌لاگ.
- افزودن تست قراردادی فاز ۹۷ برای جلوگیری از عقب‌گرد راهنماها، قالب PR و دستورهای مشارکت.

## سازگاری

- Schema همچنان نسخه ۱۶ است.
- Migration، Dependency و تغییر Runtime جدیدی وجود ندارد.
- Backup، Recovery، IndexedDB، Build و رابط محصول تغییر نکرده‌اند.

## بررسی پیشنهادی

```bash
npm run check:quality
npm run check:release
```
