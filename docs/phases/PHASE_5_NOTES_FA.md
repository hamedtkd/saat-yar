# فاز ۵ — موتور حقوق و حریم خصوصی مالی

## امکانات
- افزودن مزایا و کسورات ثابت ماهانه
- محاسبه حقوق کارکرد، اضافه‌کاری، تعطیل‌کاری و کسری
- نمایش فیش حقوقی تخمینی در گزارش‌ها
- دکمه سراسری چشم در Header برای مخفی‌کردن اطلاعات مالی
- مخفی‌سازی مبلغ‌ها در گزارش‌ها و صفحات پروژه
- ارتقای Schema از ۷ به ۸ و Migration خودکار

## نکته
فیش حقوقی یک برآورد شخصی بر پایه داده‌های ثبت‌شده و تنظیمات کاربر است و جایگزین محاسبه رسمی واحد مالی یا قوانین سازمانی نیست.
