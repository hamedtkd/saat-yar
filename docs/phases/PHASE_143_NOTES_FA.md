# فاز ۱۴۳ — تثبیت محاسبه وقفه کارمند و Patchهای رکورد

## مسئله واقعی

Browser Journey فاز ۱۴۲ تا پایان روز، ورود به ویرایش تاریخی و ذخیره خروج `17:00` جلو رفت؛ اما UI کارکرد خالص را `۸:۳۰` نشان داد، در حالی که قرارداد دامنه برای `08:00–17:00` با ناهار بدون حقوق ۳۰ دقیقه‌ای و وقفه بدون حقوق ۱۵ دقیقه‌ای برابر `۸:۱۵` است.

## اصلاح

- `updateRecord` در کنترلر حضور و غیاب دیگر Patch را روی snapshot قدیمی `record` merge نمی‌کند؛ Patch روی آخرین رکورد موجود در `previous.records[selectedDate]` اعمال می‌شود. این کار جلوی بازنویسی ناخواسته Lunch/Break در تعامل‌های سریع و transition پایان روز را می‌گیرد.
- ویرایشگر وقفه اکنون کنترل واقعی «با حقوق» دارد؛ کاربر می‌تواند برای هر وقفه صریحاً Paid/Unpaid را تغییر دهد.
- Employee Browser Smoke پس از ثبت و ویرایش وقفه، صریحاً Unpaid بودن آن را بررسی می‌کند و سپس انتظار `۸:۱۵` را روی Today/Month/Hard Reload ادامه می‌دهد.
- تست دامنه مستقل ثابت می‌کند `540 - 30 - 15 = 495` دقیقه (`۸:۱۵`).

## قرارداد انتشار

Schema همچنان v17 است، Migration و Dependency جدید نداریم. Release Candidate 2.3.0 فقط بعد از سبزشدن کامل Employee Browser Journey شروع می‌شود؛ بنابراین Candidate به فاز ۱۴۴ و Release نهایی به فاز ۱۴۵ منتقل شده است.
