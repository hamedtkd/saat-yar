# فاز ۷۴ — سخت‌گیری قرارداد Fixture رکورد کاری

## هدف

رفع خطای TypeScript باقی‌مانده در تست مرکز سلامت داده و جلوگیری از تکرار خطاهای مشابه هنگام اضافه‌شدن فیلدهای اجباری جدید به `WorkRecord`.

## تغییرات

- فیلد اجباری `holiday` به Fixture تست اضافه شد.
- Fixture دستی فاز ۷۲ با سازنده مشترک و Type-safe جایگزین شد.
- فایل `tests/fixtures/work-record.ts` به‌عنوان منبع واحد رکورد پایه تست‌ها اضافه شد.
- سازنده مشترک از `Partial<WorkRecord>` برای Overrideهای متمرکز استفاده می‌کند و تمام فیلدهای اجباری فعلی را مقداردهی می‌کند.
- تست Regression جدیدی برای قرارداد Fixture اضافه شد.

## نتیجه مورد انتظار

`npm run typecheck` دیگر روی فقدان `holiday` در فاز ۷۲ متوقف نمی‌شود و تغییرات بعدی قرارداد `WorkRecord` فقط در یک Fixture مرکزی نیاز به اصلاح خواهند داشت.
