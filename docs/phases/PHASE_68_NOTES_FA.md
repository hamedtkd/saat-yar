# فاز ۶۸ — محافظت از تغییر تاریخ با Draft تاریخی ذخیره‌نشده

## هدف

جلوگیری از گم‌شدن تغییرات رکورد تاریخی وقتی کاربر وسط ویرایش، تاریخ دیگری را از انتخابگر شمسی باز می‌کند.

## تغییرات

- Draft رکورد تاریخی در رجیستری سراسری تغییرات ذخیره‌نشده ثبت می‌شود.
- نام رکورد تاریخی در Dialog نمایش داده می‌شود.
- تغییر تاریخ از `requestNavigation` عبور می‌کند.
- کاربر می‌تواند تغییرات را ذخیره کند، دور بریزد یا در همان تاریخ بماند.
- متن Dialog از حالت مخصوص تنظیمات به متن عمومی بخش و تاریخ تغییر کرد.

## داده و Migration

- Schema بدون تغییر و روی نسخه ۱۵ باقی مانده است.
- Migration و Dependency جدیدی اضافه نشده است.
