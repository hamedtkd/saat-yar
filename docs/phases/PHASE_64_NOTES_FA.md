# فاز ۶۴ — Heartbeat نشست کاری و همگام‌سازی تایمر ناهار

## هدف

- ثبت دوره‌ای آخرین زمان فعال یک نشست کاری باز برای بازیابی پس از Crash یا خاموشی ناگهانی.
- جلوگیری از بسته‌شدن اشتباه نشست هنگام Reload عادی با آستانه stale.
- نمایش فوری ساعت شروع ناهار در TimePicker پس از فشردن دکمه شروع.

## تغییرات

- افزودن `SESSION_HEARTBEAT_KEY` و helperهای ایجاد، Parse و اعمال Heartbeat.
- ثبت Heartbeat هر ۳۰ ثانیه و هنگام `pagehide` یا مخفی‌شدن صفحه.
- بستن رکورد باز در اجرای بعدی فقط وقتی Heartbeat حداقل ۹۰ ثانیه قدیمی باشد.
- ثبت `autoClosedReason: "stale-session"` و `needsReview: true`.
- Remount کنترل شروع و پایان ناهار هنگام تغییر مقدار بیرونی برای همگام‌شدن نمایش.

## کیفیت

- تست بسته‌شدن نشست stale.
- تست بازماندن نشست در Reload عادی.
- تست همگام‌شدن ورودی شروع ناهار.
- تست نصب Heartbeat دوره‌ای و رویدادهای چرخه عمر صفحه.
