# فاز ۳۵ — پولیش پوسته و تراکم بصری

در این فاز پوسته اصلی ساعت‌یار بعد از بازطراحی بزرگ سبک‌تر و منسجم‌تر شد.

## تغییرات

- کاهش سایه Header، Sidebar و Toast
- گروه‌بندی اکشن‌های Header در یک سطح مشترک
- کوچک‌ترشدن کنترل‌های آیکنی بدون کاهش دسترس‌پذیری
- ساده‌سازی Workspace Switcher و Dropdown
- کاهش ارتفاع و فاصله Navigation دسکتاپ
- ظریف‌ترشدن نشانگر مسیر فعال
- کاهش Focus Ring از چهار پیکسل به دو پیکسل
- استفاده از transition رنگ به‌جای transition همه ویژگی‌ها
- کاهش فاصله ابتدای محتوای صفحات

## هدف

کاهش حس قاب‌درقاب، Outlineهای زیاد و سایه‌های سنگین، بدون حذف تفکیک سطوح یا Focus قابل مشاهده.
