# فاز ۳۸ — کنتراست پویا و Checkbox مدرن

## هدف
رفع مشکل ثابت‌ماندن رنگ متن و آیکن هنگام تغییر Accent و جایگزینی Checkboxهای بومی پراکنده با یک کنترل مشترک، مدرن و دسترس‌پذیر.

## تغییرات
- محاسبه خودکار `--accent-foreground` بر اساس روشنایی Accent.
- محاسبه خودکار `--accent-strong` برای تم روشن و تاریک.
- اعمال توکن‌ها پیش از Hydration و در Runtime.
- اضافه‌شدن `components/ui/checkbox.tsx` بدون dependency جدید.
- مهاجرت Checkboxهای تنظیمات، برنامه هفتگی، اعلان‌ها، مزایا، ناهار و ثبت دستی.
- اضافه‌شدن تست Regression برای کنتراست و استفاده از Checkbox مشترک.
