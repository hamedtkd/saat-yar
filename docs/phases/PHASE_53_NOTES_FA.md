# فاز ۵۳ — پروفایل کاربر و تثبیت کیفیت رابط

## تغییرات
- کارت «پروفایل و نام نمایشی» به تنظیمات عمومی اضافه شد.
- نام کاربر با قرارداد مداد، ذخیره و انصراف و Draft مستقل ویرایش می‌شود.
- در صورت فعال‌بودن ذخیره خودکار، نام بلافاصله ذخیره می‌شود.
- اعتبارسنجی فارسی، محدودیت ۵۰ نویسه و پیش‌نمایش خوشامدگویی اضافه شد.
- رنگ ثابت سفید در سطح چاپ نمودار با توکن معنایی تم جایگزین شد.
- تست قدیمی کارت امروز با ساختار Textarea جدید هماهنگ شد.

## داده و مهاجرت
- Schema همان نسخه ۱۵ است.
- Migration جدید لازم نیست؛ فیلد `settings.name` از قبل وجود داشت.
- Dependency جدیدی اضافه نشده است.
