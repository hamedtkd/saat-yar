# فاز ۱۲۸ — گروه‌بندی Navigation تنظیمات و Scroll Spy

## هدف

کاهش شلوغی Sidebar تنظیمات بدون از دست‌دادن دسترسی مستقیم به کارت‌ها و بدون شکستن Scroll Spy فازهای ۱۲۲ و ۱۲۶.

## تغییرات

- خطای TypeScript صفحه About از دو نام آیکن برند که در نسخه نصب‌شده `lucide-react` وجود نداشتند حذف شد و آیکن‌های عمومی سازگار جایگزین شدند.
- Navigation دسکتاپ تنظیمات به چهار گروه باز/بسته‌شونده تبدیل شد؛ گروه بخش فعال به‌صورت پیش‌فرض باز است و عنوان گروه در حالت بسته نیز وضعیت بخش فعال را نشان می‌دهد.
- Scroll Spy همچنان با `useSyncExternalStore` از موقعیت واقعی کارت‌ها و hash تغذیه می‌شود و state محلی فقط وضعیت باز/بسته بودن گروه‌ها را نگه می‌دارد.
- Navigation موبایل دو سطح دارد: ردیف گروه‌ها و ردیف کارت‌های گروه فعال. این کار تعداد زیاد مقصدها را بدون یک نوار افقی بسیار طولانی قابل دسترس نگه می‌دارد.
- گروه و آیتم فعال هنگام اسکرول به‌صورت خودکار در نوار مربوطه قابل مشاهده می‌مانند.
- مدل Navigation helperهای typed برای یافتن گروه و آیتم‌های هر گروه دارد تا Search، Scroll Spy و UI از یک Source of Truth استفاده کنند.

## قرارداد داده

Schema همچنان v17 است. Migration و dependency جدیدی اضافه نشده است.
