# فاز ۱۰۶ — یکپارچه‌سازی طراحی ماه، گزارش‌ها و تنظیمات

این فاز زبان طراحی نهایی ساعت‌یار را از صفحه «امروز» و App Shell به سه صفحه پرتکرار دیگر منتقل می‌کند، بدون تغییر در منطق محصول، Schema، Backup یا IndexedDB.

## تغییرات اصلی

- ایجاد `SectionHeading` مشترک برای ایجاد سلسله‌مراتب بصری یکسان در صفحات داده‌محور.
- هماهنگ‌کردن `SurfaceCard` با `dashboard-card`، `--dashboard-border` و Surfaceهای چندتمی.
- بازچینی صفحه «ماه من» به سه بلوک روشن: تقویم و روند، جزئیات روز، جدول کارکرد.
- تقویت state انتخاب روز در تقویم با Accent فعال و حفظ وضعیت‌های تعطیل، مرخصی، کامل و کسری.
- بازچینی صفحه گزارش به چهار مرحله: فیلتر، خلاصه، نمودار، جدول.
- هماهنگ‌کردن فیلترها، Chart shell و فیش حقوقی با زبان طراحی آبی‌ـ‌فیروزه‌ای و تم‌های جایگزین.
- گروه‌بندی تنظیمات در چهار ناحیه مستقل: عمومی و ظاهر، داده و پشتیبان، برنامه کاری و حقوق، عملیات حساس.
- حفظ Anchorهای فعلی تنظیمات و Unsaved Navigation Guard.
- اصلاح شماره‌گذاری نقشه راه واقعی پس از فاز ۱۰۵.

## ایمنی داده

- AppData Schema: v16
- Migration جدید: ندارد
- Dependency جدید: ندارد
- فرمت Backup: بدون تغییر
- IndexedDB: بدون تغییر
- منطق حقوق: بدون تغییر؛ موتور قابل‌سفارشی‌سازی همچنان برای فازهای ۱۱۰ و ۱۱۱ برنامه‌ریزی شده است.
