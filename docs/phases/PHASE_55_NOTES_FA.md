# فاز ۵۵ — ویرایش دستی برنامه کاری

- کارت تنظیمات کاری به Draft مستقل منتقل شد.
- تغییرات تا زدن دکمه ذخیره وارد داده اصلی نمی‌شوند.
- انصراف، تمام تغییرات همان جلسه را کنار می‌گذارد.
- در صورت فعال بودن ذخیره خودکار، تغییرات فوراً ذخیره می‌شوند.
- هدف هفتگی و روزهای هفته داخل همان Draft محاسبه می‌شوند.
- تست قدیمی Sticky با offset واقعی ۸۴ پیکسل هماهنگ شد.
