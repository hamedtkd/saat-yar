# فاز ۱۱۱ — موتور حقوق قابل سفارشی‌سازی

## هدف

جداکردن محاسبه حقوق از یک فرمول ثابت و ایجاد موتور Rule-based قابل توسعه، بدون تغییر نتیجه کاربران فعلی.

## تغییرات

- اضافه‌شدن `PayrollCalculationPolicy` با روش‌های ماهانه متناسب، ماهانه ثابت، ساعتی و روزکاری.
- امکان تعیین مستقل اضافه‌کاری و تعطیل‌کاری با ضریب، نرخ ساعتی ثابت یا نادیده‌گرفتن.
- امکان اعمال یا نادیده‌گرفتن کسرکار و تعیین ضریب آن.
- امکان گردکردن مبلغ با گام دلخواه.
- خروجی Breakdown پایدار برای UI توضیح‌پذیر فاز بعد.
- انتقال توابع قدیمی محاسبه حقوق روی Preset سازگار با رفتار فعلی.

## Schema

AppData در این فاز همچنان v16 است. دلیل این تصمیم این است که موتور ابتدا به‌صورت Pure و Backward-compatible تثبیت شود. فاز ۱۱۲ Policy را به Settings اضافه می‌کند و همان‌جا Migration و Backup contract به نسخه بعدی ارتقا پیدا می‌کنند.

## ایمنی

- رفتار محاسبه فعلی گزارش‌ها تغییر نمی‌کند.
- Dependency جدید نداریم.
- داده کاربر و Backup تغییر نمی‌کنند.
