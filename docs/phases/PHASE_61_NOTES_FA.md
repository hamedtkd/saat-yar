# فاز ۶۱ — محافظ تغییرات ذخیره‌نشده تنظیمات

## هدف

جلوگیری از گم‌شدن Draft کارت‌های تنظیمات هنگام جابه‌جایی بین بخش‌ها یا بستن صفحه.

## تغییرات

- رجیستری مشترک Draftهای تنظیمات اضافه شد.
- `useSettingsDraft` وضعیت Dirty و عملیات ذخیره/انصراف را در رجیستری ثبت می‌کند.
- ناوبری داخلی تنظیمات قبل از ترک بخش، تغییرات ذخیره‌نشده را بررسی می‌کند.
- پنجره هشدار سه انتخاب دارد: ذخیره و ادامه، ادامه بدون ذخیره، ماندن در بخش.
- رویداد `beforeunload` برای بستن یا Reload صفحه فعال شد.
- فایل `components.json` برای قرارداد shadcn/ui پروژه اضافه شد.
- کامپوننت Alert Dialog با API سازگار با shadcn و توکن‌های RTL پروژه اضافه شد.

## محدودیت

رجیستری npm محیط ساخت، بسته Radix مربوط به Alert Dialog را ارائه نمی‌کرد. بنابراین این فاز از پیاده‌سازی دسترس‌پذیر مبتنی بر استانداردهای مرورگر با API مشابه shadcn استفاده می‌کند. در محیطی که بسته رسمی در دسترس باشد، جایگزینی داخلی بدون تغییر مصرف‌کنندگان ممکن است.
