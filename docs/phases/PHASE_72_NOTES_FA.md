# فاز ۷۲ — مرکز سلامت داده و رفع قرارداد تست Draft

در این فاز خطای TypeScript تست فاز ۶۱ با افزودن `label` به Fixture برطرف شد. همچنین کارت «سلامت داده‌ها» به بخش داده و پشتیبان تنظیمات اضافه شد تا رکوردهای ناقص، نامعتبر و بسته‌شده خودکار در یک نمای قابل اقدام نمایش داده شوند.

## قابلیت‌ها
- خلاصه تعداد رکوردهای نامعتبر، ناقص و نیازمند بررسی
- نمایش حداکثر هشت رکورد اخیر دارای مشکل
- لینک محافظت‌شده برای بازکردن مستقیم همان تاریخ در صفحه امروز
- Empty State مشخص در نبود مشکل
- استفاده از `record-health` به‌عنوان منبع واحد تشخیص وضعیت

## کیفیت
- تست قرارداد فعلی Registry
- تست جمع‌آوری و خلاصه‌سازی سلامت داده
- تست اتصال کارت به تنظیمات و لینک مستقیم رکورد
