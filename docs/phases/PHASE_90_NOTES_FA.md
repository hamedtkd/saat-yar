# فاز ۹۰ — ایمنی رفتار ذخیره تنظیمات و رفع قرارداد پیش‌نمایش ظاهر

## هدف

این فاز آخرین کارت باقی‌مانده از مهاجرت تنظیمات به الگوی مشاهده، ویرایش، ذخیره و انصراف را تکمیل می‌کند و خطای TypeScript پیش‌نمایش ظاهر فاز ۸۹ را نیز برطرف می‌کند.

## تغییرات

- کارت «رفتار ذخیره تنظیمات» همیشه با ویرایش و ذخیره صریح تغییر می‌کند؛ حتی وقتی ذخیره خودکار فعال است.
- فعال‌کردن ذخیره خودکار در حضور پیش‌نویس کثیف کارت‌های دیگر مسدود می‌شود.
- نام کارت‌های مانع در پیام هشدار نمایش داده می‌شود.
- شناسه رجیستری هر Draft از Hook مشترک در اختیار مصرف‌کننده قرار می‌گیرد تا کارت بتواند خودش را از بررسی Dirty State کنار بگذارد.
- رجیستری Draft APIهای بررسی تغییرات سایر کارت‌ها را اضافه می‌کند.
- رنگ‌های پیش‌نمایش ظاهر با قرارداد صریح `PreviewColors` و fallback قطعی ساخته می‌شوند تا هیچ CSS token مقدار `undefined` نگیرد.
- مورد قدیمی هماهنگی چند تب در بک‌لاگ به‌عنوان تکمیل‌شده علامت‌گذاری شد.

## قرارداد ایمنی

- تغییر گزینه ذخیره خودکار هیچ‌گاه همان لحظه اعمال نمی‌شود.
- فعال‌سازی ذخیره خودکار نمی‌تواند Draft باز کارت دیگری را بی‌صدا از بین ببرد.
- ذخیره گروهی محافظ ناوبری همچنان می‌تواند همه Draftها را در یک چرخه ذخیره کند.

## داده و Migration

- نسخه Schema همچنان ۱۶ است.
- Migration و Dependency جدیدی اضافه نشده است.
- ساختار Backup و IndexedDB تغییر نکرده است.
