# فاز ۱۲۷ — دقت برنامه کاری، Reminder UI و صفحه درباره

## هدف

این فاز سه بدهی مستقل اما کوچک پس از پالیش ناوبری را می‌بندد: نمایش ناهماهنگ ساعت پایان بعد از تغییر هدف هفتگی، چیدمان مبهم تیک یادآوری استراحت، و نبود یک مقصد داخل محصول برای راهنما، کد منبع و ارتباط با سازنده.

## تغییرات

- `TimePicker` هنگام تغییر کنترل‌شده مقدار از والد remount می‌شود تا ساعت پایان محاسبه‌شده بلافاصله در UI دیده شود.
- تغییر دستی شروع/پایان/ناهار، `weeklyMinutes` را با مجموع واقعی برنامه همگام نگه می‌دارد.
- هدف روزانه به‌جای عدد اعشاری مانند `10.6 ساعت` با عبارت دقیق ساعت و دقیقه نمایش داده می‌شود.
- چیدمان یادآوری استراحت اصلاح شد تا Checkbox متعلق به همان عنوان باشد و روی آیکن قهوه شناور دیده نشود.
- مسیر `/about` با راهنمای سریع، توضیح Local-first، GitHub، حمایت مالی، LinkedIn و Telegram اضافه شد.
- Footer به صفحه درباره و راهنما لینک می‌دهد و Route Guard این مسیر مکمل را بدون تغییر Last Route می‌پذیرد.
- warning باقی‌مانده فاز ۱۲۶ برای import بلااستفاده `DatabaseBackup` حذف شد.

## فازهای بعد

- فاز ۱۲۸: گروه‌های Settings قابل باز/بسته‌شدن همراه با Scroll Spy و حفظ مقصد فعال.
- فاز ۱۲۹: ساخت درجا و reusable موجودیت‌های وابسته؛ شروع با Project ↔ Client و سپس تعمیم به فرم‌های رابطه‌دار دیگر.
