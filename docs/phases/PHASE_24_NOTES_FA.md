# فاز ۲۴ — دسترسی‌پذیری، فوکوس و تعامل موبایل

این فاز زیرساخت دسترسی‌پذیری برنامه را تقویت می‌کند:

- لینک پرش مستقیم به محتوای اصلی برای کاربران کیبورد
- landmark مشخص برای محتوای اصلی
- Focus trap مشترک برای دیالوگ‌های انتخاب تاریخ و زمان
- بستن دیالوگ با Escape
- بازگرداندن فوکوس به عنصر بازکننده پس از بسته‌شدن
- جلوگیری از اسکرول صفحه پشت دیالوگ
- عنوان قابل دسترس و دکمه بستن قابل مشاهده برای دیالوگ‌ها
- Focus ring سراسری و واضح
- پشتیبانی از prefers-reduced-motion
- بهبود اندازه و رفتار لمسی کنترل‌های اصلی

Schema داده تغییری نکرده و Migration لازم نیست.
