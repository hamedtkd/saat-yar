# فاز ۲ — برنامه کاری هفتگی و شیفت‌ها

## قابلیت‌ها

- تنظیم مستقل روزهای شنبه تا جمعه
- فعال یا تعطیل‌کردن هر روز
- ساعت شروع و پایان مستقل
- ناهار مستقل برای هر روز
- محاسبه خودکار هدف روزانه و هدف هفتگی
- پشتیبانی از شیفت شب؛ برای نمونه `22:00` تا `06:00`
- استفاده از هدف همان روز در داشبورد امروز، آمار ماه، تقویم ماه و خروجی CSV ماه
- مهاجرت خودکار داده از schema v4 به v5

## حریم خصوصی مالی در نقشه راه

در فاز UX یک دکمه سراسری با آیکن چشم اضافه می‌شود. با فعال‌کردن آن، همه مبلغ‌های حساس مانند حقوق، درآمد، نرخ ساعتی، فیش حقوقی و جمع مالی با مقدار پوشیده نمایش داده می‌شوند. این وضعیت برای نمایش صفحه به همکار مناسب است و روی داده ذخیره‌شده اثری ندارد.
