# فاز ۸۹ — ویرایش امن ظاهر و رنگ‌بندی

## هدف

هماهنگ‌کردن کارت ظاهر با قرارداد مشترک ویرایش تنظیمات تا تغییر تم، رنگ اصلی، سطح کارت‌ها و گردی رابط در حالت ذخیره دستی بدون ذخیره ناخواسته انجام شود.

## تغییرات

- کارت ظاهر اکنون از `useSettingsDraft` و `EditableCardActions` استفاده می‌کند.
- در حالت ذخیره دستی، کنترل‌ها فقط پس از زدن «ویرایش» فعال می‌شوند.
- ذخیره و انصراف واقعی برای کل تنظیمات ظاهر اضافه شد.
- بازنشانی ظاهر در حالت دستی فقط Draft را تغییر می‌دهد و تا ذخیره روی برنامه اعمال نمی‌شود.
- پیش‌نمایش تم به‌صورت Scoped و مستقل از ظاهر کل صفحه ساخته شد.
- پیش‌نمایش از حالت روشن، تاریک یا تنظیم سیستم، پالت، سطح کارت و شعاع گوشه Draft استفاده می‌کند.
- رنگ سفارشی نامعتبر مانع ذخیره می‌شود و پیام فارسی قابل‌فهم نمایش داده می‌شود.
- پالت‌های آماده هنگام ذخیره Accent استاندارد خود را دریافت می‌کنند و رنگ سفارشی به حروف کوچک نرمال می‌شود.
- گزینه‌های ظاهر در حالت فقط‌خواندنی واقعاً غیرفعال هستند.

## سازگاری داده

- نسخه Schema همچنان ۱۶ است.
- Migration یا Dependency جدیدی اضافه نشده است.
- ساختار Backup و IndexedDB تغییر نکرده است.

## بررسی کیفیت

تست‌های فاز، قرارداد Draft، اعتبارسنجی رنگ، نرمال‌سازی پالت و پیش‌نمایش Scoped را پوشش می‌دهند. فایل‌های Production همچنان باید زیر سقف ۲۵۰ خط باقی بمانند.
