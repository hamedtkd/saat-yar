# فاز ۱۷۱ — Import Wizard و ورود امن داده

## هدف

کاربر بتواند بدون دست‌کاری مستقیم IndexedDB یا JSON، داده‌های قبلی خود را وارد ساعت‌یار کند و پیش از هر تغییر، نتیجه را ببیند. این فاز مبنای مسیر «داده قبلی دارم» در آنبوردینگ شخصی‌شده فاز ۱۷۲ است.

## قرارداد محصول

- Route مستقل `/import` ایجاد شد و برای موتور جست‌وجو `noindex` است.
- تمام Parsing و Preview داخل مرورگر انجام می‌شود و فایل به سرور ارسال نمی‌شود.
- Backup ساعت‌یار ابتدا Parse/Migrate/Normalize و سپس از نظر additions/conflicts/settings changes تحلیل می‌شود.
- گزینه پیش‌فرض Backup، «افزودن امن» است: تنظیمات فعلی و موارد متعارض دست‌نخورده می‌مانند و فقط موارد جدید اضافه می‌شوند.
- «جایگزینی کامل» قبل از اعمال یک فایل پشتیبان ایمنی از داده فعلی دانلود می‌کند.
- CSV/TSV برای چهار دامنه اولیه پشتیبانی می‌شود: روزهای کاری، مشتری‌ها، پروژه‌ها و هزینه‌ها.
- Headerهای فارسی و انگلیسی به‌صورت خودکار Map می‌شوند و کاربر می‌تواند Mapping هر ستون را تغییر دهد.
- تاریخ میلادی `YYYY-MM-DD` و تاریخ شمسی `YYYY/MM/DD` با ارقام فارسی/عربی/لاتین پشتیبانی می‌شوند.
- ردیف نامعتبر هیچ‌وقت اعمال نمی‌شود. تعارض‌ها به‌صورت پیش‌فرض Skip می‌شوند و Replace فقط با انتخاب صریح کاربر انجام می‌شود.
- Replace تعارض‌های CSV نیز قبل از اعمال Backup ایمنی می‌گیرد.
- پروژه باید به مشتری موجود ارجاع دهد؛ هزینه نیز باید به پروژه موجود قابل Resolve متصل شود و مشتری از همان پروژه یا ستون مشتری معتبر می‌شود. Import کور relation یا هزینه یتیم ایجاد نمی‌کند.

## Browser contract

Production Browser Smoke بعد از Onboarding وارد `/import` می‌شود، CSV واقعی مشتری را به input فایل می‌دهد، Preview را می‌بیند، Apply صریح انجام می‌دهد و وجود مشتری را در Snapshot واقعی IndexedDB تأیید می‌کند؛ سپس Journey معمول PWA ادامه پیدا می‌کند.

## داده و سازگاری

- AppData Schema همچنان v17 است.
- Migration جدیدی اضافه نشد.
- Dependency جدیدی اضافه نشد.
- Backup و Device Transfer قبلی حفظ شده‌اند.
- Route `/import` عمداً در sitemap قرار نمی‌گیرد.

## ادامه

فاز ۱۷۲ آنبوردینگ را بر اساس Employee/Freelancer/Hybrid شاخه‌بندی می‌کند و Import Wizard را به‌عنوان مسیر اختیاری ورود داده قبلی در ابتدای راه‌اندازی ارائه می‌دهد.
