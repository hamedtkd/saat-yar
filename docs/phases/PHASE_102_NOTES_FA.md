# فاز ۱۰۲ — تثبیت App Shell و Responsive

## هدف

هماهنگ‌کردن پوسته اصلی ساعت‌یار با زبان طراحی داشبورد فاز ۱۰۱ در دسکتاپ و موبایل، بدون تغییر منطق دامنه، داده یا Routeها.

## تغییرات

- یکپارچه‌شدن Offset سایدبار و محتوای اصلی با توکن‌های Shell.
- بازطراحی Header با Context صفحه، هویت کاربر و کنترل‌های فشرده‌تر.
- حفظ Workspace Switcher در عرض‌های موبایل برای دسترسی سریع به حالت کارمند/فریلنسر/ترکیبی.
- پالیش Sidebar و Active State مبتنی بر Accent انتخابی کاربر.
- تعریف مقصدهای ثابت و معنادار برای Bottom Navigation در هر Mode.
- انتقال Routeهای کم‌استفاده‌تر به پنل «بیشتر» در موبایل.
- رعایت Safe Area در دستگاه‌های موبایل و محدودکردن عرض Bottom Navigation در نمایشگرهای بزرگ موبایل.
- هماهنگی Footer و Borderها با توکن‌های Dashboard.

## ایمنی

- Schema همچنان v16 است.
- Migration جدید نداریم.
- Backup و IndexedDB تغییر نکرده‌اند.
- Route Guard و Unsaved Navigation Guard حفظ شده‌اند.
- قابلیت‌های صفحه امروز و Modeهای مختلف حذف نشده‌اند.
