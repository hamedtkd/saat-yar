# فاز ۴۶ — تثبیت Navigation API و تجربه اعلان‌ها

## تغییرات

- import تابع `getTabHref` در routeهای Today و Clients از ماژول مالک واقعی یعنی `lib/navigation.ts` انجام می‌شود.
- وضعیت مجوز اعلان در تنظیمات نمایش داده می‌شود.
- فعال‌کردن یادآوری استراحت در صورت نیاز، ابتدا مجوز مرورگر را درخواست می‌کند.
- دکمه ارسال اعلان آزمایشی اضافه شده است.
- برای مجوز مسدودشده، راهنمای فارسی نمایش داده می‌شود.
- تست رگرسیون برای جلوگیری از بازگشت import قدیمی و حذف اکشن آزمایشی اضافه شد.
