# فاز ۳۰ — بازطراحی مشتری‌ها، پروژه‌ها و فاکتورها

## هدف
یکپارچه‌کردن صفحات مالی و تجاری با Design Tokenهای ساعت‌یار، حذف رنگ‌های ثابت و تبدیل الگوهای تکراری جدول و پیشرفت بودجه به primitiveهای reusable.

## تغییرات
- بازطراحی فرم و جدول مشتری‌ها
- بازطراحی کارت‌های پروژه و صفحه جزئیات
- بازطراحی جدول فاکتورها و وضعیت‌ها
- Theme-aware شدن Input و Select سراسری
- اضافه‌شدن `ProgressBar` و `TableShell`
- پوشش Privacy Mode برای سود، درآمد، هزینه و مبلغ فاکتور
- تست جلوگیری از بازگشت رنگ‌های ثابت
