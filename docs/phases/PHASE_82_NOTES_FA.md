# فاز ۸۲ — هدف هفتگی اعشاری و نوع تغییر همگام‌سازی

- ورودی هدف هفتگی در آنبوردینگ اکنون گام نیم‌ساعتی دارد و مقدار 42.5 معتبر است.
- مقدار ساعت با گردکردن به دقیقه صحیح ذخیره می‌شود.
- پیام‌های چندتب اکنون نوع تغییر را به‌صورت attendance/settings/business/reporting/general حمل می‌کنند.
- مرکز سلامت داده نوع تغییر هر رخداد را نمایش می‌دهد.
