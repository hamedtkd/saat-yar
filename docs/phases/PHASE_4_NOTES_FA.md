# فاز ۴ — اصلاح رکورد روزانه و تشخیص رکورد ناقص

- تشخیص خودکار ورود یا خروج ناقص
- تشخیص ناهار نیمه‌ثبت‌شده یا نامعتبر
- تشخیص وقفه باز یا نامعتبر
- تشخیص مرخصی بدون نوع
- نمایش وضعیت «کامل»، «ناقص» یا «نیازمند اصلاح» در صفحه روز
- امکان پاک‌کردن امن رکورد انتخاب‌شده
- ثبت `updatedAt` و `manuallyEdited` برای ویرایش‌های دستی
- ارتقای Schema از ۶ به ۷ و Migration داده‌های قبلی
- تست مستقل سلامت رکورد

دکمه سراسری مخفی‌سازی اطلاعات مالی همچنان در فاز UX سراسری برنامه‌ریزی شده است.
