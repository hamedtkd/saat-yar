# فاز ۲۶ — Theme Foundation و ممیزی بازطراحی

- Schema داده از ۱۱ به ۱۲ ارتقا یافت.
- تنظیمات Appearance شامل mode، preset، accent و radius به داده محلی و Backup اضافه شد.
- Theme Runtime و bootstrap پیش از hydration اضافه شد تا flash تم اشتباه کاهش یابد.
- توکن‌های Light/Dark مبتنی بر CSS variables و Tailwind CSS 4 اضافه شدند.
- پالت‌های Spotify، Emerald، Ocean، Violet، Sunset و رنگ سفارشی در تنظیمات اضافه شدند.
- Theme Toggle سراسری به Header اضافه شد.
- Button، App Header، Navigation و Settings shell به اولین سری توکن‌های مشترک منتقل شدند.
- این فاز پایه طراحی است؛ بازطراحی کامل صفحه‌ها در فازهای ۲۷ تا ۳۲ انجام می‌شود.
