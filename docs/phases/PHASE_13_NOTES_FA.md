# فاز ۱۳ — پایه کامپوننت‌های قابل استفاده مجدد

این فاز نخستین بخش از ممیزی reuse است و سه primitive مشترک اضافه می‌کند:

- `PrivateMoney`: نمایش یکپارچه مبلغ و حالت مخفی مالی با برچسب دسترسی‌پذیری
- `SurfaceCard`: سطح استاندارد برای کارت‌ها و پنل‌ها
- `AlertBanner`: اعلان مشترک با tone و role مناسب

همچنین `MetricCard` اکنون `ReactNode` می‌پذیرد تا مقدارهای ترکیبی و امن مثل `PrivateMoney` بدون تبدیل نوع یا JSX تکراری استفاده شوند.

## سیاست ادامه ریفکتور

- فایل‌های بالاتر از ۲۵۰ خط باید در فازهای بعدی به feature component و hookهای کوچک تقسیم شوند.
- استخراج صرفاً بر اساس شباهت ظاهری انجام نمی‌شود؛ API مشترک باید حداقل دو مصرف واقعی داشته باشد.
- نمایش مبلغ مالی نباید با شرط‌های پراکنده `financialsHidden ? ...` توسعه پیدا کند؛ مصرف‌های جدید باید از `PrivateMoney` استفاده کنند.
- منطق داده و side effect در hook یا domain function قرار می‌گیرد و component فقط orchestration و rendering را نگه می‌دارد.
