# فاز ۸۰ — تأیید حذف رکورد و مبدأ رخدادهای همگام‌سازی

## هدف

جلوگیری از حذف ناخواسته رکورد روز و کامل‌ترکردن تاریخچه همگام‌سازی چند تب با نمایش صفحه‌ای که تغییر از آن ارسال شده است.

## تغییرات

- دکمه «پاک‌کردن رکورد روز» دیگر مستقیماً داده را حذف نمی‌کند.
- پیش از حذف، Alert Dialog با توضیح دقیق داده‌های حذف‌شونده نمایش داده می‌شود.
- اکشن حذف با متن صریح و ظاهر خطرناک از دکمه انصراف جدا شده است.
- پیام‌های BroadcastChannel اکنون `sourcePath` دارند.
- تاریخچه سلامت همگام‌سازی نام صفحه مبدأ مانند «امروز» و «تنظیمات» را نمایش می‌دهد.
- پیام‌های با مسیر نامعتبر رد می‌شوند.

## داده و مهاجرت

این تغییر Migration ندارد. `sourcePath` فقط در پیام زنده بین تب‌ها و State موقت نگهداری می‌شود و وارد IndexedDB یا Backup نمی‌شود.
