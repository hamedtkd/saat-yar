# فاز ۱۲۱ — پالیش Header، Profile، Settings و Today

## هدف

پس از بسته‌شدن Release 2.2.0، این فاز بدون تغییر Schema یا منطق کسب‌وکار روی دسترسی سریع‌تر و کاهش شلوغی رابط تمرکز می‌کند.

## Header و Profile

- پروفایل از یک بلوک نمایشی به منوی واقعی و Responsive تبدیل شد.
- اصطلاح «حساب شخصی» با «پروفایل محلی» جایگزین شد تا نبود حساب ابری/Auth اشتباه برداشت نشود.
- Profile Menu مسیر مستقیم به نام نمایشی، ظاهر، انتقال دستگاه، پشتیبان و سلامت داده دارد.
- دانلود پشتیبان و Gear تکراری از Utilityهای دائمی Header حذف شدند.
- وضعیت `saved` پس از ۲.۶ ثانیه به `idle` برمی‌گردد؛ `saving` و `error` همچنان واضح می‌مانند.
- Workspace Switcher توضیح می‌دهد هر Mode چه بخش‌هایی را فعال می‌کند.

## صفحه امروز

- Hero اختصاصی Today جایگزین Header عمومی Dashboard شد.
- دکمه‌های بیرونی «روز قبل» و «روز بعد» با Unsaved Navigation Guard کار می‌کنند.
- برای تاریخ غیرامروز، عنوان دیگر به اشتباه از واژه «امروز» استفاده نمی‌کند.
- دکمه «برگشت به امروز» برای تاریخ‌های تاریخی اضافه شد.

## Settings discoverability

- Search سریع با کلیدواژه‌هایی مانند «حقوق»، «QR»، «ظاهر» و «پشتیبان» اضافه شد.
- کارت‌های مهم Anchor مستقل دارند و Profile Menu/Search مستقیماً به همان کارت می‌روند.
- ترتیب Settings Nav با ترتیب واقعی صفحه هماهنگ شد: عمومی، داده، کار و حقوق، ایمنی.
- نام «درباره برنامه» برای بخش عملیات مخرب به «ایمنی» اصلاح شد.
- Wrapperهای گروه Settings از Border/Shadow اضافه خالی شدند تا Nested Border کمتر شود.

## قرارداد داده

- AppData Schema همچنان v17 است.
- Migration، Backup contract، Payroll policy و Device Sync protocol تغییر نکرده‌اند.
- نسخه Package همچنان 2.2.0 است؛ این تغییرات در بخش Unreleased ثبت شده‌اند.
