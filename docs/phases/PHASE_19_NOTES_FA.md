# فاز ۱۹ — ریفکتور انتخابگر تاریخ جلالی

در این فاز فایل بزرگ `components/pickers/jalali-date-picker.tsx` به یک Facade کوچک و چند ماژول متمرکز تقسیم شد.

## ساختار جدید

- `date-picker-trigger.tsx`: دکمه بازکردن انتخابگر
- `date-picker-dialog.tsx`: پوسته Dialog و دکمه امروز
- `calendar-header.tsx`: جابه‌جایی ماه و عنوان
- `calendar-grid.tsx`: سرستون روزهای هفته و شبکه روزها
- `calendar-day.tsx`: نمایش هر روز، تعطیلی و وضعیت ثبت‌شده
- `use-jalali-date-picker.ts`: state و actionهای انتخابگر
- `types.ts`: قراردادهای مشترک

## اصول رعایت‌شده

- همه فایل‌ها زیر ۲۵۰ خط هستند.
- منطق state از UI جدا شده است.
- تشخیص تعطیلی فقط در سلول روز انجام می‌شود.
- Facade اصلی به محاسبات تقویم یا تعطیلات وابسته نیست.
- تست معماری برای جلوگیری از بازگشت فایل بزرگ اضافه شده است.

این فاز مدل داده یا Schema را تغییر نمی‌دهد و Migration لازم ندارد.
