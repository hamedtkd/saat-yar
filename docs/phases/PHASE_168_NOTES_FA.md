# فاز ۱۶۸ — Leave Entitlement Contract

## هدف

اصلاح قرارداد مرخصی استحقاقی که در نسخه قبلی به‌اشتباه `26 ساعت + 16 ساعت = 42 ساعت` را به‌عنوان سهمیه کل نشان می‌داد. این فاز منطق سهمیه را از مصرف جدا می‌کند و مبنای پیش‌فرض را بر قرارداد استاندارد قانون کار قرار می‌دهد.

## مبنای محاسبه

مبنای پیش‌فرض ساعت‌یار برای نیروی تمام‌وقت مشمول ساعت کار قانونی:

- یک روز مرخصی استاندارد: `۷:۲۰` یا ۴۴۰ دقیقه.
- سهمیه سالانه: `۷:۲۰ × ۲۶ = ۱۹۰:۴۰`.
- میانگین ماهانه: `۷:۲۰ × ۲۶ ÷ ۱۲ = ۱۵:۵۳:۲۰`؛ UI آن را با دقت دقیقه `۱۵:۵۳` نمایش می‌دهد.

مقدار داخلی ماهانه اعشاری نگه‌داری می‌شود تا `۱۲ × سهمیه ماهانه` دقیقاً همان `۱۹۰:۴۰` سالانه باقی بماند و خطای گردکردن ماه‌به‌ماه جمع نشود.

## اصلاح داده قدیمی

Schema همچنان v17 است. چون دو مقدار `leaveBalanceMinutes = 26 * 60` و `monthlyLeaveMinutes = 16 * 60` پیش‌فرض‌های قدیمی و غیرقابل‌ویرایش UI بودند، Normalizer هنگام خواندن دقیق همین جفت legacy آن را به قرارداد صحیح تبدیل می‌کند:

- مانده انتقالی: صفر.
- سهمیه ماهانه: مقدار قانونی جدید.

مقادیر متفاوتی که از Backup/داده سفارشی آمده باشند به‌عنوان Override/مانده انتقالی حفظ می‌شوند و خودکار بازنویسی نمی‌شوند.

## مصرف مرخصی

- مرخصی کامل و نیم‌روز برای تک‌تک روزهای بازه محاسبه می‌شود؛ باگ قبلی که یک `dailyTarget` واحد را برای همه Entryها استفاده می‌کرد حذف شد.
- روز غیرفعال برنامه کاری، جمعه و تعطیلی رسمی/دستی سهمیه مرخصی روزانه مصرف نمی‌کند.
- مرخصی ساعتی همان دقیقه ثبت‌شده را مصرف می‌کند، مشروط به اینکه تاریخ آن روز کاری باشد.
- خلاصه صفحه مرخصی مصرف را برای سال جلالی جاری ساعت‌یار محاسبه می‌کند و مانده انتقالی را جدا از سهمیه قانونی نگه می‌دارد.

## UI

نمای قبلی سه‌کارت «سهمیه کل / مصرف‌شده / مانده» به چهار شاخص روشن تبدیل شد:

1. سهمیه ماهانه
2. سهمیه سالانه
3. مصرف‌شده امسال
4. مانده امسال

متن صفحه مبنای `۲۶ روز × ۷:۲۰ = ۱۹۰:۴۰` و عدم کسر تعطیلات/روزهای غیرکاری را صریح توضیح می‌دهد.

## درس‌های Gate فاز ۱۶۷

برای جلوگیری از Revisionهای زنجیره‌ای، فاز ۱۶۸ قبل از تحویل این قراردادها را با هم بررسی می‌کند: Domain helper، Legacy normalization، UI source contract، Package wiring و تست‌های تاریخی مرتبط. Browser smokeها در این فاز تغییر نکرده‌اند؛ بنابراین Harness قدیمی را بی‌دلیل دستکاری نمی‌کنیم و Full Gate کاربر همچنان مرجع نهایی Production/Freelancer/Employee است.
