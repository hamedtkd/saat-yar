# فاز ۷۶ — پایدارسازی قرارداد تست‌ها و نظم خودکار مستندات

## هدف

رفع چهار تست قدیمی که به نام متغیرها و شکل دقیق پیاده‌سازی وابسته بودند و افزودن پاک‌سازی خودکار فایل‌های مستندات فازی که اشتباهاً در ریشه مخزن قرار می‌گیرند.

## تغییرات

- تست ناوبری تنظیمات با نام فعلی `navigateTo` هماهنگ شد.
- تست روز تکمیل‌شده با متغیر destructureشده `record` هماهنگ شد.
- تست Draft تاریخی با callback پایدار `updateRecord` هماهنگ شد.
- اسکریپت `scripts/normalize-docs-layout.mjs` اضافه شد.
- فرمان `clean:docs` پیش از Typecheck، Lint و Test اجرا می‌شود.
- فایل‌های `PHASE_*.md` ریشه به `docs/phases/` منتقل یا در صورت تکراری‌بودن حذف می‌شوند.
- `BACKLOG_FA.md` قدیمی نیز به مسیر استاندارد roadmap منتقل می‌شود.

## Migration

Migration داده، Schema یا Dependency جدید وجود ندارد.
