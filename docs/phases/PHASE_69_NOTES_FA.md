# فاز ۶۹ — همگام‌سازی امن داده میان چند تب

در این فاز ذخیره موفق داده از طریق `BroadcastChannel` به تب‌های دیگر اعلام می‌شود. تب‌های بدون Draft محلی نسخه جدید IndexedDB را خودکار بارگذاری می‌کنند. اگر تب فعلی تغییر ذخیره‌نشده یا عملیات ذخیره فعال داشته باشد، بازخوانی متوقف و یک بنر هشدار نمایش داده می‌شود تا داده محلی بی‌صدا بازنویسی نشود.
