# فاز ۷۰ — قفل مالکیت تایمر زنده میان تب‌ها

## هدف
جلوگیری از اجرای هم‌زمان عملیات نشست کاری، ناهار، وقفه و تایمر پروژه در چند تب مرورگر.

## تغییرات
- قفل موقت مبتنی بر `localStorage` با Heartbeat پانزده‌ثانیه‌ای افزوده شد.
- پیام‌های مالکیت با `BroadcastChannel` میان تب‌ها منتشر می‌شوند.
- قفل پس از ۴۵ ثانیه بدون Heartbeat منقضی می‌شود تا تب Crash‌شده برنامه را برای همیشه قفل نکند.
- تمام اکشن‌های شروع و پایان روز، ناهار، وقفه و پروژه پیش از اجرا مالکیت را بررسی می‌کنند.
- بنر هشدار و اکشن صریح «انتقال کنترل به این تب» اضافه شد.
- قفل بر اساس تمام رکوردهای باز محاسبه می‌شود و به تاریخ انتخاب‌شده در UI وابسته نیست.

## داده و Migration
تغییری در Schema یا Backup ایجاد نشده است. قفل فقط یک وضعیت موقت مرورگر است.
