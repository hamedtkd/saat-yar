# فاز ۲۵ — تست یکپارچه Workflowها و Backup

در این فاز مسیرهای اصلی کارمند، فریلنسر، فاکتور و پشتیبان به‌صورت یکپارچه تست شدند.

## تغییرات

- استخراج ساخت و Merge فایل پشتیبان به `lib/backup-workflow.ts`
- حذف منطق تکراری Backup از Hook رابط کاربری
- تست Workflow حضور و حقوق روزانه
- تست Workflow پروژه، هزینه، سود و فاکتور
- تست Round-trip و Merge فایل پشتیبان بدون شناسه تکراری

npm run check:quality
