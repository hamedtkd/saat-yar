# فاز ۹۶ — پاک‌سازی پایدار پروفایل Smoke Test در Windows

## هدف

جلوگیری از شکست کاذب `check:release` پس از موفقیت کامل Smoke Test مرورگر، زمانی که Chrome یا Edge یک فایل موقت پروفایل را برای چند لحظه با خطای `EBUSY` یا `EPERM` قفل نگه می‌دارد.

## تغییرات

- انتقال پاک‌سازی پروفایل موقت مرورگر به ماژول مستقل `scripts/browser-profile-cleanup.mjs`.
- تکرار حذف فقط برای خطاهای موقت و شناخته‌شده Windows شامل `EBUSY`، `EPERM` و `ENOTEMPTY`.
- استفاده از Backoff کوتاه و گزینه‌های داخلی `fs.rm` برای آزادشدن Handleهای باقی‌مانده مرورگر.
- حفظ خطاهای واقعی و غیرموقت مانند `EACCES` در API سطح پایین.
- تبدیل پاک‌سازی نهایی Smoke Test به عملیات best-effort؛ قفل موقت پوشه بعد از موفقیت تست فقط هشدار می‌دهد و نتیجه محصول را شکست‌خورده اعلام نمی‌کند.
- افزودن تست رفتاری برای Retry، خطای غیرموقت و پایان موفق همراه هشدار.

## سازگاری

- Schema همچنان نسخه ۱۶ است.
- Migration و Dependency جدیدی اضافه نشده است.
- رفتار Build، Static Export، Backup و IndexedDB تغییر نکرده است.
- خود Smoke Test همچنان Runtime exception، شکست Onboarding و خطای ناوبری تاریخ را با Exit Code ناموفق گزارش می‌کند؛ فقط خطای پاک‌سازی موقت پس از پایان موفق تست غیرکشنده شده است.
