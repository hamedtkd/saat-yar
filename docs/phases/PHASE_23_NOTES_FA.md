# فاز ۲۳ — بازآرایی صفحات تجاری

در این فاز صفحه جزئیات پروژه و صفحه فاکتورها به ماژول‌های کوچک‌تر تقسیم شدند. منطق state و mutation به Custom Hook منتقل شد، نمایش مبالغ مالی با `PrivateMoney` یکپارچه شد و اجزای پروژه، هزینه، رکورد زمان، فرم فاکتور و جدول فاکتور از Facade صفحات جدا شدند.

همه فایل‌های جدید زیر ۲۵۰ خط هستند و تست معماری برای جلوگیری از بازگشت فایل‌های بزرگ اضافه شده است.
