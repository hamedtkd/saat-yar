# رسانه‌های محصول

فایل‌های این پوشه با دستور زیر از Build واقعی و دیتای نمایشی مستقل ساخته می‌شوند:

```bash
npm run media:capture
```

- `screenshots/`: تصاویر README در حالت روشن، تاریک، دسکتاپ و موبایل
- `media/`: GIF معرفی آنبوردینگ در صورت نصب بودن `ffmpeg`

اسکریپت Capture به داده واقعی کاربر دسترسی ندارد و از Fixture مخصوص رسانه استفاده می‌کند.
