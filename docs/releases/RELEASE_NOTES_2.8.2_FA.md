# ساعت‌یار v2.8.2 — سازگاری Android/Mali

نسخهٔ رفع مشکل رندر در مرورگرهای Android کم‌توان؛ طراحی اصلی دستگاه‌های جدید حفظ می‌شود.

- **Adaptive Rendering:** انتخاب خودکار حالت سبک تنها برای دستگاه‌های Android با نشانه‌های محدود سخت‌افزار.
- **Manual override:** نشانی‌های `?render=lite`، `?render=full` و `?render=auto` با ذخیرهٔ مستقل از داده‌های کاری.
- **GPU paint:** حذف افکت‌های پرهزینه از نوارهای شیشه‌ای، حلقهٔ تایمر، لوگو و تغییر تم تنها در حالت سبک.
- **PWA:** Cache نسخهٔ ۹ برای دریافت CSS/JS جدید.
- **Safety:** بدون Migration، بدون تغییر در IndexedDB، تایمر یا سایر ویژگی‌ها.

تشخیص خودکار براساس RAM/CPU تقریبی است؛ رفع کرش Native درایور Mali تنها با آزمایش مجدد روی دستگاه اصلی تأیید می‌شود.
پس از Merge و Deploy، Production Audit و تست موبایل لازم‌اند؛ Tag/Release رسمی قبل از آن ثبت نشود.
