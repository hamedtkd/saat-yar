# یادداشت انتشار ساعت‌یار ۲.۱.۰

تاریخ آماده‌سازی: **۱۶ مرداد ۱۴۰۵ / ۷ اوت ۲۰۲۶**

ساعت‌یار ۲.۱.۰ یک انتشار پایداری و آمادگی عمومی است. تمرکز این نسخه روی ایمنی داده محلی، ویرایش صریح تنظیمات، تست مرورگر Production، قراردادهای مخزن و مستندات انتشار بوده است.

## مهم‌ترین تغییرات

### ایمنی تنظیمات و ناوبری

- تکمیل الگوی مشاهده، ویرایش، ذخیره و انصراف مستقل برای کارت‌های تنظیمات.
- جلوگیری از فعال‌سازی ناخواسته ذخیره خودکار هنگام وجود Draftهای ذخیره‌نشده.
- محافظت از تغییر Route، تاریخ و History مرورگر در حضور تغییرات ذخیره‌نشده.
- مهاجرت تأییدهای مخرب و هشدار خروج به Alert Dialog رسمی Radix/shadcn.

### داده، Backup و بازیابی

- تثبیت قرارداد `AppData` روی Schema v16.
- افزودن سطل بازیابی رکوردها با نگهداری ۳۰روزه، بازیابی گروهی و پاک‌سازی رکوردهای منقضی.
- جلوگیری از ورود متادیتای فایل Backup مانند `appName` و `schemaVersion` به State برنامه.
- Audit خودکار Factory، Migration، Backup، Recovery، Snapshot و Merge با گزارش Missing، Unexpected و Invalid.
- استفاده گسترده‌تر از Fixtureهای Type-safe برای جلوگیری از شکستن تست‌ها با تغییر Schema.

### هماهنگی چند Tab و پایداری Runtime

- قفل مالکیت تایمر زنده، نمایش دستگاه مالک و امکان انتقال کنترل.
- ثبت وضعیت آخرین ذخیره خارجی، تعارض Draft و تاریخچه کوتاه رخدادهای همگام‌سازی.
- مقاوم‌سازی پاک‌سازی پروفایل موقت Chrome و Edge در Windows در برابر قفل‌های کوتاه‌مدت `EBUSY`.

### کنترل کیفیت و مرورگر

- اجرای Build واقعی Next.js و Static Export در Release Gate.
- Smoke Test مرورگر واقعی برای بارگذاری اولیه، Onboarding، Route امروز و تغییر تاریخ.
- اضافه‌شدن Dependency preflight، Schema audit خوانا و Release audit نسخه‌محور.
- اجرای موفق **۳۰۵ تست** در آخرین شواهد فاز ۹۸ پیش از آماده‌سازی این Release Candidate.

### مخزن و مستندات

- راهنمای فارسی و انگلیسی Agentها و مشارکت‌کننده‌ها.
- قالب‌های Pull Request و Issue همراه با چک‌لیست Schema، Migration و ایمنی داده.
- README انگلیسی، راهنمای عیب‌یابی Windows و `npm ci` و ماتریس سازگاری مرورگر.
- Manifest ماشینی انتشار برای هماهنگی نسخه Package، Schema، Release Notes و Release Gate.

## سازگاری داده

```text
Package version: 2.1.0
AppData schema: 16
Migration جدید در فاز ۹۹: ندارد
فرمت Backup: بدون تغییر نسبت به پایان فاز ۹۸
IndexedDB structure: بدون تغییر نسبت به پایان فاز ۹۸
Node.js: 22.x
```

Backupهای قدیمی همچنان باید از مسیر Migration نسخه‌بندی‌شده وارد شوند. فایل Backup ساخته‌شده با Schema جدیدتر از نسخه پشتیبانی‌شده رد می‌شود.

## کنترل نهایی قبل از Tag

```bash
npm ci
npm run check:release
git diff --check
git status
```

پس از موفقیت کامل کنترل‌های خودکار و بررسی دستی موارد موجود در `RELEASE_CHECKLIST_FA.md`:

```bash
git tag -a v2.1.0 -m "Saatyar 2.1.0"
git push origin v2.1.0
```
